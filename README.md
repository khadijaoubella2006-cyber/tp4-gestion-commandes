# Gestion des commandes électroniques
Application JavaScript structurée avec données liées.
## Description
Application frontend qui charge 3 fichiers JSON liés (customers, products, orders), 
relie les entités par leurs identifiants, calcule les montants et affiche les commandes.
## Structure
- index.html
- css/style.css
- data/customers.json
- data/orders.json
- data/products.json
- js/app.js
- js/dataService.j
- js/state.js
- js/selectors.js
- js/state.js
- js/view.js
## Fonctionnalités
- Indicateurs calculés
- Recherche par nom du client
- Filtre par statut et par catégorie
- Détail d'une commande
## Lancer le projet
Ouvrir index.html avec Live Server
